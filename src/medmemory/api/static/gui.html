Phase 1 Milestone: Five-Person Work Division

This ~40–50% presentation milestone covers the foundational database and orchestration core. Work is distributed across five balanced engineering roles:

Person 1: KV Storage
src/medmemory/kv/

SQLite WAL persistence, atomic batch operations, prefix scans, TTL expiry, and patient record modeling.

Person 2: Vector Search
src/medmemory/vector/

Section-aware clinical chunking, lexical embedder, FAISS/in-memory indices, and BM25 Reciprocal Rank Fusion.

Person 3: Query Router
src/medmemory/router/

Clinical abbreviation expansion, regex + gazetteer entity extraction, and deterministic multi-criteria RulesRouter.

Person 4: Orchestrator
src/medmemory/pipeline/

Scatter-gather parallel execution, cross-engine evidence merger, grounded extractive generator, and stage timings.

Person 5: API & Safety
src/medmemory/api/, cache/

FastAPI REST/SSE service, LRU cache with tag invalidation, SingleFlight coalescing, and clinical emergency red-flag guards.
